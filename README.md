# CareerPath – Career Roadmap Tracker

## Introduction
CareerPath is a web-based career roadmap tracker that helps users plan their career goals and monitor their learning progress. Users can create goals, add learning tasks, and track completed activities.

## Features
- Add career goals.
- Add multiple learning tasks under each goal.
- Mark tasks as completed.
- Display progress percentage.
- Delete career goals.
- Automatically save data using Local Storage.
- Simple and user-friendly interface.
- Responsive design.

## Technologies Used
- HTML5 – Structure of the webpage.
- CSS3 – Styling and responsive design.
- JavaScript – Adding goals, managing tasks, and calculating progress.
- Local Storage – Saving user data in the browser.

## Project Structure
```text
CareerPath/
```

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Add a career goal and learning tasks.
5. Mark tasks as completed and observe the progress percentage.

## Conclusion
CareerPath helps users organize their learning activities and track their career development. This project helped in understanding JavaScript functions, DOM manipulation, progress calculation, and Local Storage.
